# ISO-25010-RAG

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Official code repository for the paper: **ISO/IEC 25010 Knowledge-Augmented RAG Architecture for Extreme Class Imbalance in Non-Functional Requirements**

This repository contains the implementation of a novel neuro-symbolic framework that couples sublinear lexical representations with dual-channel knowledge retrieval from the ISO/IEC 25010 Software Product Quality standard.

## 🚀 Architecture Overview
The dual-stream pipeline processes raw requirements through a **TF-IDF Subword N-Gram Encoder (4000D)** and a dense **ISO/IEC 25010 RAG Retriever (28D)**, merging them via a non-linear Sigmoid Gated Attention fusion layer.

## 📁 Repository Structure
- src/: Core Python source code for data loading, classification, and evaluation.
- esults/: Output logs, numerical metrics, and cross-validation traces.
